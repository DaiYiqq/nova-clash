# 架构说明

## 分层

```
┌─────────────────────────────────────┐
│  UI 层（pages / widgets）            │
├─────────────────────────────────────┤
│  服务层（services，15 项创新功能）     │
├─────────────────────────────────────┤
│  核心层（core：桥接 / 状态 / 配置）    │
├─────────────────────────────────────┤
│  模型层（models）                     │
├─────────────────────────────────────┤
│  mihomo 内核（外部进程 + REST API）    │
└─────────────────────────────────────┘
```

## 关键类

- `ClashCore` — 内核进程生命周期管理
- `ExternalController` — mihomo REST API 客户端
- `CoreState` — 连接状态 / 节点 / 流量
- `ConfigProvider` — 应用配置读写
